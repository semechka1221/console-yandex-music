# 🎵 Консольный плеер Yandex Music

Удобный и легковесный консольный аудиоплеер на базе Яндекс Музыки. Позволяет искать, проигрывать треки и управлять локальными плейлистами прямо из терминала. Проект обладает интуитивно понятным интерфейсом и поддерживает интеграцию с Discord Rich Presence (RPC) для отображения вашей текущей музыкальной активности.

## ✨ Основные возможности

*   **Управление воспроизведением:** поиск, проигрывание треков, пауза, возобновление и остановка.
*   **Локальные плейлисты:** продуманная система создания собственных плейлистов, добавление в них треков и запуск целиком.
*   **Discord RPC (опционально):** трансляция текущего трека или статуса в ваш профиль Discord.
*   **Удобный интерфейс:** комфортное управление исключительно через текстовые команды в консоли.

## 🚀 Установка и запуск

1. **Склонируйте репозиторий:**
   ```bash
   git clone https://github.com/semechka1221/console-yandex-music.git
   cd <название репозитория>
   ```

2. **Установите зависимости:**
   Для работы плеера требуются сторонние библиотеки. Установите их с помощью pip:
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите мастер настройки:**
   Скрипт поможет вам настроить ключи доступа.
   *   **Yandex Music Token** — *обязателен* для работы плеера.
   *   **Discord Application ID** — *необязателен* (нужен только если хотите выводить статус в Discord).
   ```bash
   python setup.py
   ```

4. **Запустите плеер:**
   ```bash
   python main.py
   ```

## 📝 Как создать свой плейлист

Управление плейлистами происходит в специальном режиме. Чтобы создать плейлист и добавить туда музыку, выполните следующие шаги:

1. Перейдите в режим плейлистов: `playlists`
2. Создайте новый плейлист: `new "название плейлиста"`
3. Выберите его для редактирования: `select "название плейлиста"`
4. Найдите и добавьте трек: `add "название трека"`
5. Запустите плейлист: `play "название плейлиста"`

## ⌨️ Доступные команды

Интерфейс разделен на два режима работы.

### 🎧 Обычный режим
Команды для управления базовым воспроизведением и перехода в другие меню.

*   `play <название>` — найти и включить трек
*   `pause` — поставить музыку на паузу
*   `resume` — снять с паузы / возобновить воспроизведение
*   `stop` — полностью остановить воспроизведение
*   `playlists` — перейти в режим управления локальными плейлистами
*   `exit` — закрыть плеер

### 📁 Режим плейлистов (`Playlist Mode`)
Команды, доступные после ввода команды `playlists`.

*   `list` — показать список всех существующих локальных плейлистов
*   `new <название>` — создать новый плейлист
*   `select <название>` — выбрать плейлист для последующего добавления треков
*   `add <название трека>` — найти трек в Яндекс Музыке и добавить его в выбранный плейлист
*   `play <название>` — запустить проигрывание указанного плейлиста
*   `stop` — остановить воспроизведение текущего плейлиста
*   `leave` — выйти из режима управления плейлистами обратно в обычный режим
